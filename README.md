# 新聞配達

夜明け前の街を自転車で巡り、指定された家へ新聞を届ける一人称視点のホラーゲームです。暗闇では恐怖が高まり、怪異の危険も増します。街灯や自転車のヘッドライトを活用し、バッテリーを管理しながら、その夜の配達を完了してください。

## プロジェクト構成

- `新聞配達/新聞配達.sln`：Visual Studio ソリューション
- `新聞配達/新聞配達/`：C++ と DxLib を使ったゲーム本体
  - `Main.cpp`：DxLib 初期化、メインループ、各ゲームシステムの更新と描画
  - `SceneManager.*`：タイトル、ゲーム、クリア、ゲームオーバー、ポーズ、画面遷移
  - `Player.*` / `Camera.*` / `Bicycle.*`：徒歩、自転車、視点操作
  - `DeliveryManager.*` / `Newspaper.*` / `Mailbox.*`：配達順、新聞、ポスト
  - `BatteryManager.*`：予備バッテリーの配置・回収・交換
  - `HorrorManager.*` / `HorrorEntity.*`：恐怖度、怪異、遭遇とゲームオーバー
  - `NightEnvironment.*` / `WeatherManager.*`：夜の照明、環境、天候
  - `HorrorUI.*`：時計、恐怖度、バッテリー、操作ガイドなどの HUD
  - `Data/`：3D モデル、テクスチャ、効果音、BGM
- `prompt4.md`：開始時の遊び方ポップアップ実装に関する作業指示

## ゲームルール

1. 夜明け前に、配達順として指定されたポストへ新聞を届けます。自転車のカゴから新聞を取り、対象のポストの前で配達してください。
2. 暗闇にいると恐怖度が上昇します。街灯や自転車のヘッドライトが届く安全な光の中では恐怖を抑えられます。すべての光源が安全とは限りません。
3. 自転車のヘッドライトはバッテリーを消費します。街中の予備バッテリーを回収し、必要になったら自転車の近くで交換してください。
4. 恐怖度が限界に達すると怪異に襲われ、ゲームオーバーになります。
5. ゲームは Day 1 から Day 7 まで進みます。日数が進むと配達数や難易度が上がります。

## 操作方法

| 操作 | キー・入力 |
| --- | --- |
| 徒歩で移動／自転車を操作 | `W` `A` `S` `D` |
| 視点・照準を動かす | マウス |
| 自転車に乗る／降りる | `E` |
| 新聞を取る／ポストへ配達／アイテムを拾う | 左クリック（対象を見ているとき） |
| ヘッドライトの点灯・消灯 | `F` |
| 予備バッテリーと交換 | `R`（自転車の近く） |
| 自転車のベル／ブレーキ | `Space` |
| 走る | `Shift` |
| 遊び方を表示 | `H` |
| 操作ガイド HUD の表示切り替え | `Tab` |
| ポーズメニュー | `Esc` |
| メニュー決定 | `Enter` またはクリック |
