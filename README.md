# 新聞配達

夜明け前の街を自転車で巡り、指定された家へ新聞を届ける一人称視点のホラーゲームです。暗闇では恐怖が高まり、怪異の危険も増します。街灯や自転車のヘッドライトを活用し、バッテリーを管理しながら、その夜の配達を完了してください。

## プロジェクト構成

- `新聞配達/新聞配達.sln` : Visual Studio ソリューション
- `新聞配達/新聞配達/` : C++ と DxLib を使ったゲーム本体
  - `Main.cpp` : DxLib 初期化、メインループ、各ゲームシステムの更新と描画
  - `SceneManager.*` : タイトル、ゲーム、クリア、ゲームオーバー、ポーズ、画面遷移
  - `Player.*` / `Camera.*` / `Bicycle.*` : 徒歩、自転車、視点操作
  - `DeliveryManager.*` / `Newspaper.*` / `Mailbox.*` : 配達管理、新聞、ポスト
  - `BatteryManager.*` : 予備バッテリーの配置・回収・交換
  - `HorrorManager.*` / `HorrorEntity.*` : 恐怖度、怪異、ゲームオーバー
  - `NightEnvironment.*` / `WeatherManager.*` : 夜の照明、環境、天候
  - `HorrorUI.*` : 時計、恐怖度、バッテリー、操作ガイドなどの HUD
  - `Data/` : 3D モデル、テクスチャ、効果音、BGM

## ゲームルール

1. 夜明け前に、配達指示として指定されたポストへ新聞を届けます。自転車のカゴから新聞を取り、対象のポストの前で配達してください。
2. 暗闇にいると恐怖度が上昇します。街灯や自転車のヘッドライトが届く安全な光の中では恐怖を抑えられます。すべての光源が安全とは限りません。
3. 自転車のヘッドライトはバッテリーを消費します。街中の予備バッテリーを回収し、必要になったら自転車の近くで交換してください。
4. 恐怖度が限界に達すると怪異に襲われ、ゲームオーバーになります。
5. ゲームは **Day 1 から Day 5** まで進みます。日数が進むと配達数・難易度が上がります。

## ステージ構成（Day 1 ～ Day 5）

| Day | 曜日 | 配達数 | 天候 | 街灯 |
|:---:|------|:------:|------|------|
| 1 | MONDAY | 3件 | 晴れ | 6本点灯（1本消灯） |
| 2 | TUESDAY | 4件 | 雨 | 5本点灯（フリッカーあり） |
| 3 | WEDNESDAY | 5件 | 霧 | 4本点灯（弱点灯・フリッカーあり） |
| 4 | THURSDAY | 6件 | 大雨 | 2本点灯（ほぼ消灯） |
| 5 | FRIDAY (FINAL) | 8件 | 濃霧 | 1本のみフリッカー |

> **クリア条件** : Day 5 の配達をすべて完了するとゲームクリアとなります。

## 操作方法

| 操作 | キー・入力 |
| --- | --- |
| 徒歩で移動 / 自転車を操作 | `W` `A` `S` `D` |
| 視点・照準を動かす | マウス |
| 自転車に乗る / 降りる | `E` |
| 新聞を取る / ポストへ配達 / アイテムを拾う | 左クリック（対象を見ているとき） |
| ヘッドライトの点灯・消灯 | `F` |
| 予備バッテリーと交換 | `R`（自転車の近く） |
| 自転車のベル・ブレーキ | `Space` |
| 走る | `Shift` |
| 遊び方を表示 | `H` |
| 操作ガイド HUD の表示切替 | `Tab` |
| ポーズメニュー | `Esc` |
| メニュー決定 | `Enter` またはクリック |

## 変更履歴

### 2026-11-17

#### クリア条件の変更（7日 → 5日）
- ゲームクリアに必要なステージ数を **7日間** から **5日間** に短縮。
- `SceneManager`, `DeliveryManager`, `WeatherManager`, `HorrorManager`, `BatteryManager`, `NightEnvironment` の各モジュールで Day の上限を 5 に統一。
- Day 5 を最終日（FINAL DAY）として扱い、天候・難易度・演出を最高値に設定。

#### 電柱（街灯）の段階的減少
- ステージが進むごとに点灯している街灯の数が減り、プレイヤーを取り巻く環境がより暗く危険になる。
- `NightEnvironment::SetDayEnvironment()` を5段階設計に再構築。

| Day | 点灯数 | 状態の内訳 |
|:---:|:------:|-----------|
| 1 | 6本 | ID5 のみ消灯 |
| 2 | 5本 | ID5・ID7 消灯、ID3 フリッカー |
| 3 | 4本 | ID3・ID5・ID7 消灯、ID2 フリッカー、ID1 弱点灯 |
| 4 | 2本 | ID1・ID3・ID5・ID6・ID7 消灯、ID2 フリッカー、ID4 弱点灯 |
| 5 | 1本 | ID1 のみフリッカー、ほぼ全消灯 |
